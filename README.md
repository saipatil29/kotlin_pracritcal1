      # Practical-1: Kotlin Programming Concepts

## Aim

To develop a Kotlin program demonstrating fundamental programming concepts such as variables, type conversion, user input, control flow, functions, recursion, arrays, collections, classes, constructors, operator overloading, and matrix operations.

## Practical Contents

1. **Store & Display Values in Different Variables**
2. **Type Conversion**
3. **Scan Student Information**
4. **Check Odd or Even Numbers**
5. **Display Month Name using `when`**
6. **User-Defined Functions**
7. **Factorial using Recursion**
8. **Working with Arrays**
9. **Find Maximum Number from ArrayList**
10. **Classes and Constructors – Car**
11. **Operator Overloading and Matrix Operations**

## Learning Outcomes

After completing this practical, students will be able to:

- Work with Kotlin variables and data types.
- Perform type conversions.
- Accept and display user input.
- Use `if-else` and `when` expressions.
- Create user-defined and recursive functions.
- Work with arrays, loops, ranges, and ArrayLists.
- Create classes and constructors.
- Implement operator overloading.
- Perform matrix operations using Kotlin classes.
- Override `toString()` for customized output.

## Conclusion

This practical provides a foundation in Kotlin programming by covering basic syntax, data types, input/output, control flow, functions, recursion, arrays, collections, object-oriented programming, operator overloading, and matrix operations. These concepts form the basis for developing Kotlin applications, including Android applications.
